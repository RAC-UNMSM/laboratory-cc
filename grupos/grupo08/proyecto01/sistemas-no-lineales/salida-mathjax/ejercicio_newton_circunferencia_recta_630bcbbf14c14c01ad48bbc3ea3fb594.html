Convergencia alcanzada.

Enunciado

Encontrar las intersecciones de la circunferencia unitaria x^2 + y^2 = 1 y la recta y = x usando Newton-Raphson desde x0 = (1, 0.5).

Formulacion

\[F(x,y)=\begin{bmatrix}x^2+y^2-1\\x-y\end{bmatrix}=\begin{bmatrix}0\\0\end{bmatrix}\]

Datos del metodo

Punto inicial\(\mathbf{x}_0=\left(1, 0.5\right)\)
Tolerancia1e-08
Maximo de iteraciones100
Criterio de convergencia\(\|F(\mathbf{x}_k)\|_2 < 10^{-8}\)

Desarrollo

  1. Se define \(F(x,y)=\begin{bmatrix}x^2+y^2-1\\x-y\end{bmatrix}\).
  2. El Jacobiano es \(J(x,y)=\begin{bmatrix}2x&2y\\1&-1\end{bmatrix}\); el metodo lo aproxima con diferencias centrales.
  3. Se resuelve \(J(x_k)\,\Delta x_k=-F(x_k)\) y se actualiza \(x_{k+1}=x_k+\Delta x_k\).
  4. Se detiene cuando \(\|F(x_k)\|_2<10^{-8}\).
